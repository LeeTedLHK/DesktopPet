## 启动

双击 `artifacts/publish/p22-win-x64/DesktopPet.exe`。

分发文件为 `artifacts/DesktopPet-P22-win-x64.zip`。解压后保留整个 `p22-win-x64` 文件夹，包括 `Assets/`、`runtime/` 和 DLL；无需另行安装 .NET。旧版发布目录和压缩包均保留。

首次显示在主屏右下角，避开任务栏。右键宠物或系统托盘图标打开菜单；托盘图标也可能位于 Windows 的隐藏图标区域。Alt+F4 隐藏宠物；真正退出请使用右键菜单或托盘的“退出”。重复启动会找回已有宠物，第二个实例退出；全屏期间保持临时隐藏。

## 操作

| 操作 | 效果 |
|---|---|
| 单击头部（窗口上半部） | 摸头、满足表情与气泡 |
| 单击身体 | 开心互动 |
| 按住左键移动超过 5 像素 | 拖动宠物，可跨屏，播放悬空小爪子动作 |
| 松开拖动 | 放下宠物，至少等待 3 秒再进行随机决策 |
| 右键或托盘“喂食” | 食盆与狗粮出现在前爪前方，播放吃饭、舔嘴动作；8 秒内重复喂食会回应刚刚吃过 |
| Ctrl+Alt+P | 显示/隐藏 |
| Ctrl+Alt+M | 开启/关闭鼠标穿透 |
| 托盘双击 | 请求显示宠物 |
| 抛小球 / 抛飞盘 | 沿地面奔跑、捡球或跳接飞盘，再叼回原位并放下；够不到的飞盘落地后捡取 |
| 跟我散步（30秒） | 在当前屏幕与活动范围内跟随鼠标，靠近后停下来等待 |
| 三回合接球挑战 | 每次完整叼回后才计数；三次送达后自动结束 |
| 结束当前玩法 | 停止散步、追逐或接球挑战 |
| 保存宠物拍立得 | 保存带名字/日期的照片卡与透明头像 |
| 回小窝睡觉 | 走回小窝休息，摸头叫醒 |
| 找回宠物 / 重置位置 | 恢复可互动状态并回到当前屏幕默认位置 |
| 托盘“召唤到鼠标附近” | 显示宠物并移到鼠标附近，保留鼠标穿透和自动行为偏好；允许跨屏时跟随鼠标所在屏幕 |

开启鼠标穿透后，宠物不会接收鼠标点击或拖动，可以使用快捷键或系统托盘关闭穿透。托盘仍可摸头、喂食、打开设置与退出。气泡约 3 秒自动消失，始终让鼠标操作穿过。

鼠标位置轮询仅在宠物显示、精准点击开启且没有开启整个窗口鼠标穿透时运行；切换偏好后立即更新点击方式，隐藏或退出时停止检测。

宠物隐藏时，设置页的投球、飞盘、接球挑战、回窝和散步按钮暂停使用，并说明原因；可点“显示宠物”继续玩耍。开启全屏自动隐藏时，退出全屏后这些按钮自动恢复。显示入口保留位置和鼠标穿透偏好。

宠物名字最多20个显示字符，支持完整emoji、组合emoji、旗帜及带重音的字符；编辑结束后显示实际保存的名字。

喂食食盆独立于小窝和玩具开关，随宠物缩放、活动范围及置顶设置调整，鼠标可以穿过。完成喂食、摸头或拖动打断、隐藏、全屏自动隐藏及退出时收起；关闭动画仍会显示食盆并自动结束静态互动。

## 多屏、皮肤与开机启动

在“屏幕与皮肤”页选择显示器。活动范围相对所选屏幕计算，可关闭跨屏拖动。屏幕和物理像素位置会保存；拔掉所选显示器后自动移回主屏。气泡、小窝和全屏检测跟随宠物所在屏幕。窗口采用 PerMonitorV2 DPI 设置。

默认只让宠物图案接收点击，透明区域可操作下面的窗口；缓存当前动画帧的透明度，拖动捕获期间保持连贯。可关闭精准点击，也可开启整个窗口的鼠标穿透。JPEG 备用照片没有透明度。

支持导入皮肤文件夹或 ZIP，结构为 `Idle/000.png`、`WalkLeft/000.png` 等动作目录，可带 `skin.json` 的 `name` 字段。必须有 Idle；缺少其他动作时会提示并回退。独立副本保存在 `%LOCALAPPDATA%\DesktopPet\Skins\`，可随时切回默认比熊。

可选根部 `mouth-anchors.json` 会随皮肤导入保留，使叼回玩具跟随自定义动作的嘴部位置。支持大小写不同的文件名和一层外包装目录。“导出当前皮肤 ZIP”保存当前动作、名字及嘴部定位数据，导出的ZIP可以重新导入；默认素材的参考照片不会混入。导出失败会保留已有目标文件。

导入检查路径、链接、PNG 文件头、尺寸、数量与总体积；切换前完整解码，加载失败保留原皮肤。限制：32–2048 像素、每张 8 MiB、最多 5000 帧、总文件 128 MiB、总像素 64 Mi-pixels；名字元数据最多64 KiB，嘴部定位最多128 KiB。导出采用相同帧与体积限制。

开机自启默认关闭。开启后写入当前用户 HKCU Run 的带引号启动路径，关闭时移除；设置显示操作结果。“启动应用时显示”独立控制启动后是否显示宠物。移动发布文件夹后需在新位置重新启动以更新自启路径。

## 玩具、小窝与成长日记

在“玩具与日记”页、宠物右键或托盘抛小球/飞盘。暂停自动行为时也能玩；隐藏、全屏、拖动、主动互动或更换屏幕/皮肤/大小/活动范围等会结束玩法。名字、置顶、气泡、养成、提醒等普通偏好修改保留玩法。玩具大小修改用于下次抛出。

小球以 `Assets/Pet/小球.jpg` 为外观参考，采用红色橡胶椭圆球身、蓝色端带、白色缝线与颗粒纹理；飞盘采用青绿色软胶、厚边、凹槽与爪印。原生矢量绘制随小狗实际大小缩放；可在“玩具与日记”独立调节球、飞盘和食盆大小，默认100%保留小巧食盆。玩具的碰撞、叼取和放下位置使用同一个实际尺寸，并适配Windows显示缩放。参考球照片仅用于开发，不随运行包分发。

“一点小惊喜”提供三种玩法：散步跟随鼠标30秒，保持距离避免遮挡鼠标；接球挑战自动进行三回合，回合间短暂休息；拍立得导出640×760照片卡与原尺寸透明PNG头像。菜单展开时暂停追逐、散步与挑战，关闭全部菜单后继续；散步时长不包含菜单停留时间。可随时主动结束。

照片保存到系统“图片”目录中的 `DesktopPet` 文件夹，可在设置中打开相册。使用独立文件名保留旧照片；只读取宠物当前动画帧，不截取桌面。自定义皮肤也可以拍照。

小窝默认关闭，可选择奶油、薄荷、玫瑰三种颜色及相对位置，包含围边软床、凹入坐垫、折叠小毯子、爪印布标与小食盆。小窝会适配活动范围、大小和置顶状态。回窝后休息一分钟；夜间自动作息开启时持续睡到白天。道具让鼠标点击穿过。

日记默认开启，独立于养成数值。按本地日期记录陪伴天数，记录摸头、喂食、玩耍、回窝和完成专注；保存最近 200 条，不要求连续签到。同类动作有 10 秒记录间隔，不同动作相互独立。

“查找日记”可搜索中文、英文和emoji关键词，并按相伴、摸头、喂食等类型及全部/今天/近7天/近30天筛选。条件同时生效，按记录的本地日期计算范围，结果从新到旧排列；新记录和倒计时刷新保留筛选，跨过午夜后更新相对日期。没有结果时显示提示，可一键清除筛选。筛选只影响当前窗口的查看结果。

“导出全部日记”保存UTF-8 TXT，包含名字、照料状态、累计次数与按时间排序的日记，标明UTC时间。“导出当前筛选”单独保存符合条件的记录，并注明条件、筛选条数及总条数；累计互动次数仍表示全部陪伴记录。导出已有记录时无需开启日记；写入失败保留已有目标文件。

六个成就：初次亲近、陪伴三天、十次喂食、五次玩耍、首次回窝、三次专注。选中已解锁成就可查看并播放专属台词；关闭气泡或隐藏宠物时仍可在设置里阅读。旧版养成数据会保留并补齐日记字段。

## 不打扰模式

默认检测宠物所在显示器的前台全屏窗口，每秒刷新一次。进入全屏时临时隐藏，停止宠物动画和行为；离开全屏后恢复用户希望显示的状态。手动隐藏具有持续效果，不会因退出全屏重新出现。

设置可以关闭全屏自动隐藏、鼠标穿透及全局快捷键。快捷键注册冲突会在设置页提示，仍可用托盘操作。宠物与气泡不会因为鼠标点击抢占输入焦点。

Windows 实现采用官方 [分层窗口鼠标穿透机制](https://learn.microsoft.com/en-us/windows/win32/winmsg/window-features) 与 [RegisterHotKey](https://learn.microsoft.com/en-us/windows/win32/api/winuser/nf-winuser-registerhotkey)。

## 自然行为与作息

- 随机待机、左右走动、短暂睡眠，并增加伸懒腰和打哈欠。
- 鼠标靠近宠物约 350 DIP、且发生移动时，宠物短暂看向鼠标所在方向，观察间隔至少 12 秒。
- 夜间默认 22:00–07:00 持续睡眠，白天恢复。设置提供 24 小时起止时间；相同起止时间不安排夜间睡眠。
- 摸头、喂食与身体互动可临时叫醒宠物，15 秒内不会立即进入夜间睡眠。
- 查看宠物或托盘菜单、调整大小或置顶不会唤醒已有休息；菜单打开时暂停自动决策，白天短睡仍按原定时间结束。
- 暂停只关闭自动行为，仍可点击、拖动、摸头和喂食。

设置中的随机动作、鼠标观察、夜间睡觉和气泡可以分别关闭。动画关闭时仍保留互动文字与点击反馈，临时状态会正常结束。

“外观与互动”的省电模式默认关闭。开启后待机动画最多每秒4帧，睡眠最多每秒2帧；如果原本设置得更慢，则保留更慢速度。走路、奔跑、喂食等互动动作和专注/提醒计时不受影响；隐藏或关闭动画时仍停止播放。

## 轻量养成

右键宠物或托盘选择“宠物状态与专注…”打开设置的“陪伴与专注”页。可修改名字、查看亲密度/饱腹/精力（0–100），或关闭养成。

- 摸头、玩耍增加亲密度；喂食增加 20 饱腹，并奖励亲密度。亲密度奖励每分钟最多一次。
- 程序运行且宠物显示时，饱腹每小时减少 3，清醒精力每小时减少 6，睡眠每小时恢复 12。
- 退出、手动隐藏、全屏自动隐藏或关闭养成时不扣数值；没有死亡和强制照顾。系统长时间挂起每次最多计算 5 分钟变化。
- 低精力会让自动行为更倾向休息，不限制主动互动。保存时采用原子替换；坏文件备份后恢复默认。

## 健康提醒与番茄钟

“陪伴与专注”页可以分别开启喝水、起身、放松眼睛提醒，默认全部关闭。间隔可选 15–120 分钟，默认 45/60/30 分钟。计时仅在程序运行期间有效，重启后从新间隔开始。

番茄钟默认专注 25 分钟、休息 5 分钟；可以开始、暂停、继续、停止。专注结束自动进入休息，休息结束等待手动开始下一轮。时长修改用于下一轮；不会覆盖当前倒计时。当前状态同时显示在设置页与托盘子菜单，右键宠物也可操作。退出程序结束当前会话。

可一键选择25/5、45/10、60/10分钟预设，分别设置下一轮专注与休息时长；当前计时和玩法保持不变。进度条按当前阶段的真实时长计算，休息阶段重新从零开始；运行时显示预计本地结束时间，暂停时保留进度并收起旧估计，继续后更新。

“专注时安静陪伴”默认关闭。开启后，正在计时的专注阶段暂停自动行为和健康提醒，仍可主动摸头、喂食和玩耍；暂停专注、进入休息或停止后恢复。专注阶段结束提示仍正常排队。托盘悬停可查看宠物名字、显示/互动状态与倒计时，长emoji名字完整截断。

健康提醒可延后15/30/60分钟，也可提前恢复。延后不影响番茄钟；普通设置修改保留延后截止时间，重启后重新按正常间隔计时。提前恢复从每种健康提醒的正常间隔开始，避免旧提示集中出现。

提醒使用现有气泡与伸懒腰动作，无声音、无强制弹窗。全屏、隐藏、关闭气泡、拖动、右键/托盘菜单展开或互动中暂不显示。按类型合并，超过 10 分钟丢弃；两次提示至少间隔 2 分钟，番茄阶段结束优先。关闭一个健康提醒或停止番茄钟会清除相应待发提示。

## 性格与活动范围

性格可选默认、活泼、安静、黏人。活泼更常走动、等待较短；安静更常待在原地、等待较长；黏人观察附近鼠标的间隔缩短为 6 秒。已有行为频率和夜间作息仍生效。

活动范围可选所选屏幕整个工作区、底部（25% 高）、右下角（30% 宽高）或自定义百分比矩形。拖动、自动走动、位置恢复、缩放和屏幕变化共享边界限制。自定义区域以工作区的左、上、宽、高百分比保存，越界会收缩；太小则向内扩大到可容纳完整宠物。

## 素材

P7 以 `pet.jpg`、三视图和已选P6外形基准生成60张基础动作及72张过渡/叼回动作。P21只以 `小狗行走.mp4` 的步态规律校正左右各8帧行走，P22进一步校准行走、起步、停步与转身的头部比例及接口。原比熊的头脸、耳毛、表情、卷尾、红花项圈和金色铃铛特征保留，生成素材仍有细微毛边和脚趾变化；奔跑及其他动作素材保留。当前共29个动作目录、172张256×256透明动作帧，运行包另有两张原始参考图和一份嘴部定位数据。球照片和行走视频保留在源码中，只用于开发参考。

内置ImageGen原始图、弃用候选、深色预览和动画GIF保存在 `artifacts/imagegen/p7/base/`、`motion/`；提示词及来源：[基础动作](docs/assets/2026-10-04-p7-base-prompts.json)、[过渡与叼回](docs/assets/2026-10-04-p7-motion-prompts.json)。两个 `prepare-p7-*-assets.py` 脚本只拆完整单元、统一整帧缩放/平移并生成检查预览，不变形身体、不镜像方向、不重建透明蒙版。转身第二版的透明间隔不等宽，因此沿完整单元之间的透明间隔切分，八帧仍使用同一个像素缩放比例。旧基础帧存于 `artifacts/imagegen/p7/previous-runtime/`，两张参考图原样保留。

左右行走均8帧15fps（默认一轮约0.533秒），参考视频的短步幅、低抬脚节奏并保持原角色外形；通用回退行走10fps、奔跑12fps、叼回10fps，起步/刹停/转身8fps。开心8帧以5fps播放，默认约1.6秒；普通互动与追逐庆祝同步使用实际皮肤时长和速度设置。捡取、放下和跳跃按实际玩法进度推进，避免动画与玩具状态脱节。腾空时长限制为0.28–0.7秒；较慢动画设置仍保持这个物理时长，完整跳跃姿态随进度播放。嘴部定位随每帧变化，玩具不会因为换帧停留在旧位置。旧皮肤缺少过渡时直接进入目标动作。相邻帧仍可能有细微毛发变化，素材是原角色的腿部动画编辑，并非逐像素动作捕捉。玩具与小窝继续采用WPF矢量绘制。

伸懒腰和打哈欠以2fps播放现有六帧，默认约3秒；时长随动画速度设置调整，防卡住计时覆盖完整动作。

## 设置与日志

配置：`%LOCALAPPDATA%\DesktopPet\settings.json`。养成状态：同目录 `profile.json`。日志：同目录 `logs\`。养成独立保存，设置修改不会覆盖新数值。

“数据与帮助”页可选择位置保存数据备份ZIP，也可打开数据和日志目录。备份包含当前设置、养成数值、完整日记及格式说明；导出不会修改正在使用的数据，写入失败会保留原备份。照片、日志、导入皮肤和正在计时的专注会话不在此备份内；皮肤请单独导出。此轮不提供自动覆盖恢复功能。

同一页面集中说明快捷键、找回宠物、互动、叼回、散步、暂停、隐藏和退出。版本号自动读取当前程序。托盘与设置中的小球/飞盘/挑战入口随玩具开关禁用，小窝入口随小窝开关禁用；隐藏期间托盘不能启动这些需要显示宠物的动作。

设置立即生效、500ms 防抖保存；拖动结束、自动移动结束及退出保存位置。配置写入采用临时文件与原子替换，损坏 JSON 备份后恢复默认值。旧版本配置自动获得新增字段的默认值。

保存提示同时反映设置与养成、日记的写入结果。养成保存失败后每10秒重试，恢复后回到每分钟保存；单独养成保存成功不会掩盖设置保存失败。重新打开设置页也会显示最近的保存结果。

新增字段：`FullscreenAutoHide=true`、`ClickThrough=false`、`GlobalHotkeysEnabled=true`、`SpeechBubblesEnabled=true`、`NaturalBehaviorsEnabled=true`、`CursorTrackingEnabled=true`、`NightSleepEnabled=true`、`NightSleepStartHour=22`、`NightSleepEndHour=7`。

原设置包括置顶、自动行为、启动应用时显示、宠物大小0.8–2.0、动画开关、动画速度0.25–3.0、移动速度和行为频率。动画速度界面覆盖完整范围，并保留已有的任意合法精确值；修改其他设置不会将速度改成预设档位。“启动应用时显示”仍不是开机自启。

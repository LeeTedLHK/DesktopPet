# P17 / 0.9.8 验收记录

日期：2026-10-05（北京时间）。本轮处理参考小球、狗窝、开心动作速度与行走爪子生硬四项反馈。

## 实现

小球以 `src/DesktopPet/Assets/Pet/小球.jpg` 为参考，改成钝圆两端的红色橡胶橄榄球，增加蓝色端带、七条白色缝线及颗粒纹理。仍由WPF矢量绘制，随原有大小设置缩放。旋转时保持在32DIP道具范围内。放下时按球身可见底边校准落地位置，沿原有轨迹平滑下落；原生渲染实测底边658.233DIP、脚下地面658.5DIP。追逐使用原有碰撞模型，叼回仍跟随嘴部。

狗窝增加立体围边、凹入坐垫、滚边缝线、折叠小毯子、爪印布标和软阴影，保留奶油、薄荷、玫瑰三种主题及原有大小/活动范围。食盆继续复用独立喂食道具。210×90DIP画布统一缩放，保持鼠标穿透。

开心动画由8帧9fps（约0.89秒）调整为5fps（约1.6秒），单次完整播放后恢复。追玩具后的庆祝从原来约0.6秒改为实际开心片段时长；开始玩法时捕获当前皮肤和速度对应的秒数，避免速度重复应用。默认0.25倍约6.4秒、3倍约0.53秒；自定义皮肤按实际帧数计算。隐藏或主动互动仍能打断。P16伸懒腰/打哈欠默认约3秒的节奏保留。

左右行走分别根据原来的两张比熊参考图重新生成12个透明姿态，重点加强后腿收腿、抬脚和落脚。以12fps循环播放，默认一轮1秒；通用回退行走仍为10fps，奔跑、叼回、起步/刹停/转身及其他动作素材保留。当前29个动作目录，共180张动作帧。

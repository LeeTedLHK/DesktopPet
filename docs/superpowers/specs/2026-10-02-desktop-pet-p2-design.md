# DesktopPet P2：安静陪伴与互动

用户已要求实现上一轮建议的 1、2、3，并使用 Assets/Pet 中两张图片生成相应素材。本任务直接在现有目录完成；目录没有 Git 元数据，保留源码备份，不创建新仓库。

## 行为

- 全屏自动隐藏默认开启，每秒检测前台窗口是否覆盖其所在显示器，并排除桌面、任务栏和本进程窗口。退出全屏只恢复用户希望显示的宠物；手动隐藏不会被全屏退出覆盖。
- Ctrl+Alt+P 显示/隐藏，Ctrl+Alt+M 切换鼠标穿透。快捷键开关即时生效；冲突在设置中可见，托盘始终可操作。穿透默认关闭，不抢窗口焦点。
- 左键头部摸头、身体开心；右键菜单与托盘提供摸头、喂食。拖动有专用姿势与气泡，松开后恢复。喂食冷却 8 秒；互动可打断睡眠或移动，也可在暂停时播放。动画关闭时仍有文本和点击反馈，不会卡住临时状态。
- 随机伸懒腰、打哈欠；鼠标靠近且移动时短暂看向左右，不跟随移动宠物；12 秒观察冷却。夜间默认 22:00–07:00 睡眠，跨午夜、关闭及修改时间均可正常恢复。手动互动可临时唤醒。
- 气泡约 3 秒自动关闭，贴近宠物且不超出工作区、不占鼠标操作区域；隐藏、全屏、退出时清理。

## 结构与兼容

纯逻辑放在 Core：可见性意图、夜间时间段、全屏矩形判断、状态机与自然动作选择。WPF 负责 Win32 全屏检测/穿透/快捷键、气泡、鼠标观察与计时。设置仍使用现有 JSON、防抖、原子保存，旧文件使用新字段默认值。

新增 Petting、Feeding、Stretching、Yawning、Dragging、LookLeft、LookRight 动画，缺少素材沿用 Idle 回退；互动/伸展/哈欠单次，观察/拖动循环。素材保持白色卷毛比熊、红项圈、黄色铃铛、透明背景，现有素材与两张原图保留。新精灵图按等格切为 256×256 PNG，保存生成提示与来源。
